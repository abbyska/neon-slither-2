# Neon Slither 2 🐍✨

A modern, neon-themed take on the classic Snake game, optimized for both desktop and mobile web browsers.

## 🎮 Play Now
Clone the repo and open `index.html` in your browser!

## ✨ Features
- **Premium Neon Aesthetic**: Glowing visuals, smooth animations, and a dark mode interface.
- **Mobile Optimized**: Swipe controls and responsive canvas that adapts to any screen size.
- **Leaderboard System**: Local storage-based leaderboard to track top scores and player names.
- **Funny Identity**: Automatically assigns you a fun "Neon" identity (e.g., "Neon Noodle", "Cyber Cobra").
- **Difficulty Levels**: Choose your challenge level - Beginner, Advanced, or Expert.

## 🕹 Controls
- **Desktop**: Use `Arrow Keys` to turn.
- **Mobile**: `Swipe` anywhere on the screen to change direction.

## 🛠 Tech Stack
- **HTML5 Canvas** for rendering.
- **Vanilla JavaScript** for game logic (no heavy frameworks).
- **CSS3** for styling and animations.

## 🚀 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/abbyska/neon-slither-2.git
   ```
2. Open `index.html` in your favorite web browser.
